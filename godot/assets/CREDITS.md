# Ассеты «Пепел Угасшего Солнца»

Все файлы в `sprites/`, `tiles/`, `bg/` — оригинальные, нарисованы для проекта кодом (PIL), лицензия CC0 (public domain).
Все файлы в `audio/` — синтезированы кодом (Python wave), лицензия CC0.

Сторонние паки НЕ вендорятся в репозиторий из-за лицензий itch.io, качаются вручную:
- Герой: rvros «Animated Pixel Adventurer» (CC0) — https://rvros.itch.io/animated-pixel-hero-adventurer
- Рыцарь/мобы: aamatniekss «Fantasy Knight», LuizMelo «Monsters Creatures Fantasy» (CC-BY, указать автора в титрах)
- Фоны: Anokolisa «Gothic Dungeon» (проверить лицензию на странице пака)

Референс стиля HUD/боёвки: скриншоты пользователя (сторонняя игра, стиль не копируем 1-в-1, только настроение: тёмный фон, луна, руины, бары снизу).
