# Warrior of Death

Тёмная action-RPG в духе Diablo: арена, волны мобов, лут, прокачка, босс.

## Статус
Прототип арены: Canvas-изометрия, tap-to-move, автоатака, волны, HP-бары.

## Сборка
Пуш в `main` или ручной запуск `Build APK` собирает release-APK в GitHub Actions.
Готовый APK падает в артефакты и отправляется в Telegram (секреты `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).
